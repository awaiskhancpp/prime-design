# Redirects and SEO Reference

Preserve old identity where useful:
```text
legacyWpId
legacySlug
legacyPermalink
```

Use:
- 301 for permanently moved content
- 410 for intentionally removed content

Validate:
```text
old URL → status → destination → correct content
```

Also verify title, description, canonical URL, sitemap behavior, and internal links.
